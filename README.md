# Моя визитка

Простой сайт-визитка, созданный в рамках изучения
основ программирования и работы с Git.

## О проекте

На странице представлена информация обо мне
и технологиях, которые я изучаю.

## Используемые технологии

- HTML5 — структура страницы
- CSS3 — оформление сайта
- Git — контроль версий
- GitHub — хранение репозитория

## Как запустить

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта.
3. Запустить файл `index.html` в браузере.
